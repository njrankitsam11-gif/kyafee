# The Daily Roast (TDR) — Mindful Habit Replacement & Coffee Curation

A niche coffee curation web platform and behavioral gamification framework designed to help complete beginners replace destructive oral and hand fixations (smoking, alcohol, digital restlessness) with the tactile, sensory craft of manual coffee brewing.

---

## 🌟 Core Product Features Built

### 1. The Brain-Triggering Hook (Habit Replacement Science)
- **Bilateral Hand & Motor Fixation Grounding:** Replaces the physical motor void of smoking (flicking lighters, rolling papers, holding glasses) with precision knurled aluminum burr grinding, 0.1g digital scale measurement, and controlled spiral pouring.
- **Earned Dopamine vs. Chemical Crash:** Contrasts the synthetic spike and subsequent anxiety dip of nicotine/alcohol with the sustained, earned dopamine of 4.5-minute mindful extraction.
- **Interactive Web Audio Soundboard:** Synthesizes the crunching acoustic resistance of manual steel burrs, precision 0.1g scale tare beeps, and blooming CO2 sizzle directly in the browser via the Web Audio API.

### 2. Gamified Mood & Taste Scan (Interactive Onboarding)
- **4-Step Interactive Diagnostic:**
  - *Step 1: Somatic Vibe Check* (Restless hands, mental fog, or evening decompression).
  - *Step 2: Sensory Palate Mapping* (Dark Cacao/Pecan, Wild Berry/Jasmine, or Brown Sugar/Vanilla).
  - *Step 3: Vice Trigger Window* (3:00 PM Stress Smoke, 8:00 PM Drink, or Morning Anxiety).
  - *Step 4: Extraction Archetype Assignment* (e.g., **Pour-Over Paladin**, **Aeropress Alchemist**, **French Press Philosopher**).

### 3. The Smart Intake Tracker & Mind Dashboard
- **Visual Caffeine & Circadian Balance Meter:** Real-time visual progress bar monitoring intake against a 350mg daily safe cap with circadian sleep cutoff time calculation (2:30 PM cutoff for 10:30 PM sleep).
- **Habit Replacement Scoreboard:** Live tracking of Days Clean, Cravings Diverted, and Tactile Mindful Minutes Earned.
- **Beginner Milestone Badges:** Unlockable achievements (*First Fresh Grind*, *The Golden Bloom*, *3-Day Clean Streak*, *Circadian Guardian*, *Panic Hero*).
- **Interactive Cup Logger:** Select brew method and the specific craving replaced to immediately update the balance meter and habit score.

### 4. Just-In-Time Smart Bean Replenishment
- **Depletion Engine:** Automatically calculates remaining beans (15g–20g per cup from a 250g bag).
- **Dynamic Low-Supply Trigger:** When 4 cups remain (~72 hours before running dry), the platform prompts an automated, frictionless 1-tap replenishment trigger before the user's hopper runs empty.
- **Interactive Notification Simulation:** Preview the SMS/Push alert and confirm dispatch with 1 click.

### 5. Emergency "Panic Brew" Protocol (SOS Craving Interception)
- A guided **3-minute sensory intervention timer** with rhythmic breathing ring animation.
- Breaks down the critical 180-second craving peak into 5 tactile actions that occupy both hands until the acute urge dissipates.

## 🚀 How to Run Locally

You can launch the web application instantly using the included Python server or by opening `index.html` in any modern web browser:

### Option A: Using the Python Server (Recommended)
```bash
python3 server.py
```
This automatically serves the app on `http://localhost:8000` (or the next available port) and opens your default browser.

### Option B: Direct File Open
Simply double-click `index.html` in your file explorer or open it in Safari/Chrome:
```bash
open index.html
```
